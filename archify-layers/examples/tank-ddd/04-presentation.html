表现层对象

长图

答

结论

表现层把按键变成指令，把两个上下文画到窗口上。它是这条支线的类层。

  1. 只有这里 import pygame。
  2. 绘制只读状态，不改胜负。
  3. 爆炸和结束提示由表现层自己记着。

适用于表现层提交 2ae47a6b

1

由什么组成？

三个对象：键盘翻译、组装入口、绘制器。没有更小的阅读层。1

图的结构
  • 键盘翻译 keys
  • 组装入口 main
  • 绘制器 view
  • keys → main · Command
  • main → view · 每帧绘制
2

各自负责什么？

对象做不做
to_command把按下的键变成 Command，其它事件返回空不推进游戏
main创建对象，按 60 FPS 循环，每 10 帧调用一次 update不判定碰撞
Renderer按地形和坦克画格子，订阅击毁、解锁、新高分不改 Game 规则

每秒 6 个游戏格，因为 FPS // TICKS_PER_SECOND 等于 10。1

方向键、空格、回车、P、S、L 有对应指令。其它键没有。2

3

怎样交互？

按键先变成 Command。入口把它交给会话，到点再 update，然后 draw。绘制器另外订阅三条事件，用来记爆炸和两句英文提示。3

图的结构
  • 键盘 keys
  • 入口 main
  • 对战会话 session
  • 绘制 view
  • keys → main · Command
  • main → session · handle
  • main → view · draw

Renderer 直接读 Game 的坦克、子弹和地图来画。这是绘制对领域对象的依赖，不是领域对 pygame 的依赖。

4

生命周期

入口创建 Renderer，并持有到退出。绘制器自己持有爆炸列表和提示句子：击毁时追加。画面处于对战中时，提示会被清空。3

本层不适用一张状态机。原因：菜单、暂停、结束是 GameSession.screen，在对战类那一页。绘制器只读取它。

5

下钻

本层不适用下一层。原因：键盘函数、入口和绘制器已经是这条支线的对象，阅读地图里没有更低的层。
